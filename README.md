# Python-Based Portfolio Builder

## Description
A Python-based tool that allows users to create a professional portfolio website by simply inputting their details (projects, skills, experience, etc.). The program generates a fully responsive and well-designed HTML/CSS portfolio using Jinja2 templates and Bootstrap, making it accessible for users without any web development skills.

---

## Features
- **Customizable Inputs**: Enter personal details, projects, skills, and experience in an easy-to-use format.
- **Responsive Design**: Automatically generates a responsive portfolio using Bootstrap.
- **Template-based**: Uses Jinja2 templates for flexibility and easy customization.
- **Beginner-friendly**: No web development knowledge required.
- **Portable**: Share or host the portfolio online easily.

---

## Installation

Prerequisites
- Python 3.8 or later
- `pip` package manager

Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/python-portfolio-builder.git
   ```
2. Navigate to the project directory:
   ```bash
   cd python-portfolio-builder
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

---

Usage
1. Run the script:
   ```bash
   python app.py
   ```
2. Fill in the requested details (e.g., name, projects, skills, and experience).
3. The program will generate an HTML file in the `output` folder.
4. Open the generated HTML file in your browser to view your portfolio.
